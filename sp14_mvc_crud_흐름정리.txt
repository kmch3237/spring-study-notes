  sp14에서 CRUD는 컨트롤러가 기능별로 각각 분리되어 있다.

  ┌─────────────────────────────────────────────────────────┐
  │  기능       │  관련 컨트롤러                            │
  ├─────────────────────────────────────────────────────────┤
  │  목록 조회  │  EmployeeListController                   │
  │  등록 폼    │  EmployeeInsertFormController             │
  │  등록 실행  │  EmployeeInsertController                 │
  │  수정 폼    │  EmployeeUpdateFormController             │
  │  수정 실행  │  EmployeeUpdateController                 │
  │  삭제 실행  │  EmployeeDeleteController                 │
  └─────────────────────────────────────────────────────────┘

  ※ Department / Position / Region 도 동일한 구조로 구성됨

○ 핵심 용어 정리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  mav.addObject("키", 값)
    → 컨트롤러에서 JSP로 데이터를 전달하는 방법
    → 키 이름이 JSP에서 ${키} 로 사용됨

  mav.setViewName("뷰이름")
    → 어떤 JSP 파일로 이동할지 결정
    → ViewResolver가 /WEB-INF/views/뷰이름.jsp 로 변환

  request.getParameter("name속성값")
    → JSP 폼에서 넘어온 데이터를 꺼내는 방법
    → <input name="employeeId"> → getParameter("employeeId")

  redirect:xxx.action
    → 브라우저에게 새 주소로 다시 요청하라고 지시
    → 등록/수정/삭제 후 새로고침 중복 처리 방지용


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
○ INSERT 흐름
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  전체 흐름:
  EmployeeList.jsp → InsertFormController → EmployeeInsertForm.jsp
                   → InsertController → redirect → EmployeeList.jsp

  ─────────────────────────────────────────
  1단계: InsertFormController
  ─────────────────────────────────────────

  목적: 빈 등록 폼을 보여주기 위해 select박스용 목록 데이터를 가져옴

  // EmployeeInsertFormController.java
  regionList     = dao.regionList();      // 지역 목록 조회
  departmentList = dao.deparmentList();   // 부서 목록 조회
  positionList   = dao.positionList();    // 직위 목록 조회

  mav.addObject("regionList", regionList);
  mav.addObject("departmentList", departmentList);
  mav.addObject("positionList", positionList);

  mav.setViewName("EmployeeInsertForm");  // 등록 폼 JSP로 이동

  ※ Update와 달리 기존 데이터 조회(searchId) 없음 — 빈 폼이기 때문

  ─────────────────────────────────────────
  2단계: EmployeeInsertForm.jsp
  ─────────────────────────────────────────

  빈 input 필드들 + addObject로 받은 select박스 목록 표시

  <form action="employeeinsert.action" method="post">

    <input type="text" name="name">         ← 이름 (비어있음)
    <input type="text" name="ssn1">         ← 주민번호 앞자리
    <input type="text" name="birthday">     ← 생년월일

    <select name="regionId">
      <c:forEach var="region" items="${regionList}">
        <option value="${region.regionId}">${region.regionName}</option>
      </c:forEach>
    </select>

  </form>

  ─────────────────────────────────────────
  3단계: InsertController
  ─────────────────────────────────────────

  // EmployeeInsertController.java
  String name         = request.getParameter("name");
  String ssn1         = request.getParameter("ssn1");
  String birthday     = request.getParameter("birthday");
  String regionId     = request.getParameter("regionId");  // select의 value(ID)가 전송됨
  // ... 나머지 필드들

  Employee employee = new Employee();
  employee.setName(name);
  employee.setSsn1(ssn1);
  employee.setBirthday(birthday);
  employee.setRegionId(regionId);
  // ...

  int result = dao.add(employee);   // DB INSERT 실행

  if (result > 0) {
      mav.setViewName("redirect:/employeelist.action");     // 성공 → 목록으로
  } else {
      mav.setViewName("redirect:/employeeinsertform.action"); // 실패 → 폼으로
  }

  ─────────────────────────────────────────
  INSERT 데이터 흐름 요약
  ─────────────────────────────────────────

  [DB 목록 조회]
       │
  addObject("regionList", ...)
       │
       ▼
  [InsertForm.jsp]
  items="${regionList}" → select박스에 표시
  사용자가 값 입력/선택
       │
  form submit (POST)
  name="name", name="regionId" ...
       │
       ▼
  [InsertController]
  getParameter("name") → Employee 객체에 set
  getParameter("regionId")
       │
  dao.add(employee) → DB INSERT
       │
       ▼
  redirect → 목록 페이지

○ UPDATE 흐름
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  전체 흐름:
  EmployeeList.jsp → UpdateFormController → EmployeeUpdateForm.jsp
                   → UpdateController → redirect → EmployeeList.jsp

  ─────────────────────────────────────────
  1단계: UpdateFormController
  ─────────────────────────────────────────

  목적: 수정할 직원의 기존 데이터 + select박스용 목록을 가져와서 폼에 채워줌

  // EmployeeUpdateFormController.java
  String employeeId = request.getParameter("employeeId");   // 목록에서 클릭한 직원 ID

  Employee employee  = employeeDAO.searchId(employeeId);    // 기존 데이터 1건 조회
  regionList         = regionDAO.list();
  departmentList     = departmentDAO.list();
  positionList       = positionDAO.list();

  mav.addObject("employee", employee);           // 기존 직원 데이터
  mav.addObject("regionList", regionList);
  mav.addObject("departmentList", departmentList);
  mav.addObject("positionList", positionList);

  mav.setViewName("EmployeeUpdateForm");

  ※ Insert와 차이점: searchId()로 기존 데이터를 1건 추가로 조회함
  ※ DAO가 4개 필요해서 employeeDAO, regionDAO, departmentDAO, positionDAO
     를 모두 DI 받음 (servlet-context.xml에 property 4개 등록)

  ─────────────────────────────────────────
  2단계: EmployeeUpdateForm.jsp
  ─────────────────────────────────────────

  input의 value에 기존 데이터가 미리 채워짐

  <input name="name"  value="${employee.name }">        ← addObject의 "employee" 키
  <input name="ssn1"  value="${employee.ssn1}">
  <input name="employeeId" value="${employee.employeeId}" readonly>  ← 사원번호 수정 불가

  select박스: 현재 값이 selected 처리됨

  <select name="regionId">
    <c:forEach var="region" items="${regionList}">
      <option value="${region.regionId}"
        ${employee.regionId == region.regionId ? "selected='selected'" : ""}>
        ${region.regionName}
      </option>
    </c:forEach>
  </select>

  화면에 보이는 것: "서울", "부산" 등 이름(regionName)
  실제 전송되는 것: "1", "2" 등 ID(regionId) — option의 value 속성

  radio 버튼 (양/음력):

  <input type="radio" value="0" name="lunar"
    ${employee.lunar==0 ? "checked='checked'" : ""}> 양력
  <input type="radio" value="1" name="lunar"
    ${employee.lunar==1 ? "checked='checked'" : ""}> 음력

  ─────────────────────────────────────────
  3단계: UpdateController
  ─────────────────────────────────────────

  // EmployeeUpdateController.java
  String employeeId = request.getParameter("employeeId");
  String name       = request.getParameter("name");
  String regionId   = request.getParameter("regionId");   // select에서 선택한 ID
  // ... 나머지 필드들

  Employee employee = new Employee();
  employee.setEmployeeId(employeeId);
  employee.setName(name);
  employee.setRegionId(regionId);
  // ...

  dao.modify(employee);   // DB UPDATE 실행

  mav.setViewName("redirect:employeelist.action");

  ─────────────────────────────────────────
  UPDATE 데이터 흐름 요약
  ─────────────────────────────────────────

  [DB에서 기존 데이터 조회 — searchId()]
       │
  addObject("employee", employee)   ← 기존 직원 1건
  addObject("regionList", ...)      ← select박스용 목록
       │
       ▼
  [UpdateForm.jsp]
  value="${employee.name}"          → input에 현재 값 표시
  regionId == 비교 → selected       → select에 현재 값 표시
  사용자가 수정
       │
  form submit (POST)
  name="name", name="regionId" ...
       │
       ▼
  [UpdateController]
  getParameter("name") → Employee 객체에 set
  getParameter("regionId")
       │
  dao.modify(employee) → DB UPDATE
       │
       ▼
  redirect → 목록 페이지

○ DELETE 흐름
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  전체 흐름:
  EmployeeList.jsp → DeleteController → redirect → EmployeeList.jsp

  ※ 삭제는 폼 페이지(DeleteForm)가 없음 — 목록에서 바로 실행

  ─────────────────────────────────────────
  DeleteController
  ─────────────────────────────────────────

  // EmployeeDeleteController.java
  String employeeId = request.getParameter("employeeId");  // 목록에서 넘어온 ID

  dao.remove(employeeId);  // DB DELETE 실행 (ID 하나만 넘기면 끝)

  mav.setViewName("redirect:employeelist.action");

  ─────────────────────────────────────────
  DELETE 데이터 흐름 요약
  ─────────────────────────────────────────

  [EmployeeList.jsp]
  삭제 버튼 클릭
  → employeedelete.action?employeeId=3   (또는 form hidden 방식)
       │
       ▼
  [DeleteController]
  getParameter("employeeId") → "3"
       │
  dao.remove("3") → DB DELETE
       │
       ▼
  redirect → 목록 페이지

○ Insert / Update / Delete 비교표
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌──────────────┬──────────────────┬──────────────────┬─────────────────┐
  │              │ INSERT           │ UPDATE           │ DELETE          │
  ├──────────────┼──────────────────┼──────────────────┼─────────────────┤
  │ 컨트롤러 수  │ 2개              │ 2개              │ 1개             │
  │              │ (Form + 실행)    │ (Form + 실행)    │ (실행만)        │
  ├──────────────┼──────────────────┼──────────────────┼─────────────────┤
  │ Form 조회    │ select박스 목록  │ 기존 데이터 1건  │ 없음            │
  │              │ (searchId 없음)  │ + select박스 목록│                 │
  ├──────────────┼──────────────────┼──────────────────┼─────────────────┤
  │ input value  │ 비어있음         │ 기존값 미리 채움 │ 해당없음        │
  ├──────────────┼──────────────────┼──────────────────┼─────────────────┤
  │ DAO 메서드   │ dao.add()        │ dao.modify()     │ dao.remove()    │
  ├──────────────┼──────────────────┼──────────────────┼─────────────────┤
  │ 완료 후      │ redirect 목록    │ redirect 목록    │ redirect 목록   │
  └──────────────┴──────────────────┴──────────────────┴─────────────────┘

○ addObject 키 이름 vs input name 속성 정리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌──────────────────────────┬──────────────────────────────────────────┐
  │ 컨트롤러 (Java)          │ JSP                                      │
  ├──────────────────────────┼──────────────────────────────────────────┤
  │ addObject("employee", e) │ ${employee.name}  → Employee.getName()   │
  │ addObject("regionList",r)│ items="${regionList}"  → forEach 반복    │
  ├──────────────────────────┼──────────────────────────────────────────┤
  │ input name="name"        │ getParameter("name")                     │
  │ input name="regionId"    │ getParameter("regionId")                 │
  │ option value="${id}"     │ 화면엔 이름, 전송은 ID                   │
  └──────────────────────────┴──────────────────────────────────────────┘

  핵심:
  - addObject 키 = JSP에서 ${} 안에 쓰는 이름
  - input/select의 name = getParameter()에 넣는 이름
  - option의 value = 실제 전송되는 값 (화면에 보이는 텍스트와 다름)
