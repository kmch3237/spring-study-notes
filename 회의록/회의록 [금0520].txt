회의록 [금0520]

[회의 개요]
카페관리자 / 예약/매칭 상세논의  


[회의 내용]
1. 카페 관리자 
  
- 사용자 사이트에서 관리해라	
- 카페/ 테마를 동시 승인 

- 관리자 권한 범위 논의
  1. 사장은 모든 권한 / 매니저는 특정 권한(예약조회, 예약취소, 출석체크)
             (해당매니저 그만두면 삭제/새로운 매니저 추가 할 수 있게)			
  2. 

- 예약 오픈 날짜 
  1. 테마별 시간을 매니저가 일일히 입력(부득이 하게 특정날 문 닫을때..)
  2. 입력하고 고정



- 예약/매칭 흐름 논의
  1.예약 먼저 
    - 3명이상이 필요한 예약을 먼저했을때 문제가 생긴다..

  2. 매칭먼저 
   (현재 방탈출도 이런 구조
   매칭을 먼저하면 파티안에 파티가 생길 수있다 시간을 정하지 않았으니깐
    = 결정이 안 나서 기능 제거로 넘어감 



 - 기능 제거 
 1. 이메일 알림기능(다 날리고 강제 취소상황만 남기기)
 2. 메시지보드 내용 조회·삭제
 3. 테마 검색 -> 단순 카페명/테마명 검색 -> 복잡한 검색 제거
 4. 


다시 
 예약/매칭 흐름 논의로 돌아와서
 예약먼저하는걸로 결정
 (우린 예약이 제일 메인)
