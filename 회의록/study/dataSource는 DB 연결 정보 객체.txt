dataSource는? DB 연결 정보 객체

public class DriverManagerDataSource {
    private String url;        // DB 주소
    private String username;   // 계정
    private String password;   // 비밀번호
    private String driverClassName;  // Oracle 드라이버
    
    public Connection getConnection() {
        // 위 정보로 Oracle 연결해서 Connection 반환!
        return DriverManager.getConnection(url, username, password);
    }
}
어떻게 만들어지나?
<!-- 1. 외부 파일에서 값 읽기 -->
<context:property-placeholder

# jdbc.properties (별도 파일)
jdbc.driverClass=oracle.jdbc.driver.OracleDriver
jdbc.uri=jdbc:oracle:thin:@//127.0.0.1:1521/xe
jdbc.username=scott
jdbc.password=tiger

<!-- 2. 값을 객체에 주입 -->
<bean id="dataSource" 
      class="org.springframework.jdbc.datasource.DriverManagerDataSource">
    <property name="driverClassName" value="${jdbc.driverClass}"/>
    <property name="url" value="${jdbc.uri}"/>
    <property name="username" value="${jdbc.username}"/>
    <property name="password" value="${jdbc.password}"/>
</bean>

- beans  <beans> 태그 - "객체 만들어줘!"

<beans:bean id="memberDAO" class="com.doit.app.service.MemberDAO"/>

MemberDAO memberDAO = new MemberDAO();

왜 beans: 접두사가 붙어?
xml<!-- servlet-context.xml 맨 위 -->
<beans:beans xmlns="http://...mvc"           ← 기본 네임스페이스
             xmlns:beans="http://...beans">  ← beans 네임스페이스
xml기본 네임스페이스 = mvc
   ↓
<resources/> ← 그냥 쓰면 mvc 태그!

beans는 별도 표시 필요
   ↓
<beans:bean/> ← beans 네임스페이스의 bean 태그!
servlet-context.xml은 MVC가 메인이라 bean이 손님이에요!
(반대로 root-context.xml은 beans가 메인이라 그냥 <bean> 으로 씀)



- property = 값 넣어줘!
<beans:bean id="memberDAO" class="...MemberDAO">
    <beans:property name="dataSource" ref="dataSource"/>
              ↑       ↑                  ↑
           setter 호출  필드명          참조할 bean
</beans:bean>


= name 속성의 마법
<property name="dao" .../>
              ↑
        setter 이름 결정!

스프링 내부 동작:
"dao" → 첫 글자 대문자 → "Dao" → "set" + "Dao" = setDao()

public void setDao(IMemberDAO dao) { ... }
//            ↑ 이걸 호출함!
그래서 property name과 setter 이름이 정확히 맞아야 해요!


○ value vs ref 차이
<!-- value: 진짜 값 넣기 -->
<property name="url" value="jdbc:oracle:..."/>
                       ↑ 그냥 문자열

자바: setUrl("jdbc:oracle:...");


<!-- ref: 다른 bean 참조 -->
<property name="dataSource" ref="dataSource"/>
                              ↑ 다른 bean id

자바: setDataSource(dataSource객체);

- mav.addObject
addObject() - "데이터 담아!"
mav.addObject("count", count);
//             ↑ key   ↑ value

내부적으로 일어나는 일:
 ModelAndView 내부 (대충)
public void addObject(String name, Object value) {
    model.put(name, value);  // Map에 저장!
}

ModelAndView 내부:
┌──────────────────────────┐
│       model (Map)        	│
│                          	│
│  "count"      → 3        	│
│  "memberList" → [홍길동...] │
│                         	│
│       viewName               │
│  "memberList"                │
└──────────────────────────┘

Controller
    │
    ├─ mav.addObject("count", 3);
    ├─ mav.addObject("memberList", list);
    ├─ mav.setViewName("memberList");
    │
    ▼
return mav;
    │
    ▼
DispatcherServlet이 받음
    ├─ "viewName이 memberList네?"
    │   → ViewResolver로 JSP 찾음
    │   → /WEB-INF/views/memberList.jsp
    │
    ├─ "model에 데이터 있네?"
    │   → JSP에 request 속성으로 전달
    │
    ▼
JSP 실행
    ├─ ${count}      → 3 출력
    └─ ${memberList} → 리스트 출력

              addObject의 첫 번째 인자!
